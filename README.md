# Rekisa WhatsApp Automation

Standalone project for the WhatsApp Automation landing page. The landing page is served at `/`; the original support pages, audit flow, contact flow, tests, backend and project configuration are included so this project can be developed and deployed independently.

## Run locally

- Frontend: `cd frontend`, then `npm install` and `npm start`.
- Backend: `cd backend`, then `pip install -r requirements.txt` and run the configured FastAPI server.

See `design-guidelines.md` for the visual system and `test_result.md` for the inherited verification record.
