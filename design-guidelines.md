# Design guidelines

- Use the Rekisa palette: deep navy for foundations, electric purple and teal for system cues, and coral for conversion actions.
- Use Space Grotesk or Poppins for display headings and Inter for body copy; use mono styling only for labels and metadata.
- Keep one primary call to action per section, make buttons high contrast, and retain the existing responsive spacing and card patterns.
- Preserve accessible semantic headings, visible focus states, meaningful image labels and readable colour contrast.
